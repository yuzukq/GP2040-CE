アケコンの設定と書き込み

neo は GP2040-CE のフォークです。レバー方向で出し分ける Mod ボタンと、日本語の設定画面を追加しています。 設定画面はコントローラー本体から配信されるので、ネットに繋がっていなくても使えます。

1設定画面を開く

  1. コントローラーの USB を抜く
  2. Start を押しながら USB を挿す（ボタン未配線なら、端子台の START と GND を繋いだまま挿す）
  3. 数秒待ってから、下のボタンで開く
neo.local を開く 192.168.7.1 を開く 開けないとき

neo.local は Mac・Windows 10/11 ならそのまま使えます。Linux で開けないときは avahi を入れるか、192.168.7.1 を使ってください。

2最新のファームウェア

ビルド情報を読み込み中…

基板ファイル
Pico Fighting Board
たこた工房 typeC など		 neo_PicoFightingBoard.uf2
Raspberry Pi Pico
Pico に手で配線した場合		 neo_Pico.uf2

3書き込む

  1. 書き込みモードにする: neo の設定画面で 3 設定 → 書き込みモードで再起動、または基板の BOOT ボタンを押しながら USB を挿す
  2. PC に RPI-RP2 というドライブが出る
  3. ダウンロードした .uf2 をそのドライブにコピーする
  4. コピーが終わると自動で再起動して、コントローラーとして使える

保存した設定（ボタン配置・Mod のキャラ設定など）は書き込み後も残ります。
